# news-monitor

Автопостинг в Telegram-канал по расписанию (GitHub Actions, `.github/workflows/news-monitor.yml`).

## Рубрики

| Слот (МСК) | Рубрика | Что публикуется |
|---|---|---|
| 6:00, 12:00, 15:00, 18:00 | humor | мем с картинкой: лучший по лайкам пост из телеграм-канала, иначе текстовая шутка |
| 9:00 | service | пост о готовом сервисе/инструменте по статье (текст пишет Groq) |

## Источники

- **Сервисы:** habr.com, vc.ru, tproger.ru (RSS).
- **Мемы:** телеграм-канал `t.me/package_memes` через веб-превью `t.me/s/package_memes`.
- **Текстовые шутки:** anekdot.ru (RSS), запасной вариант, если картинок нет.
- Пикабу из списка убран 09.11.2026: в «горячее» попал комикс с оскорблениями по национальному
  признаку, а фильтры видят только текст, не картинку.

## Как выбирается мем

1. Читается веб-превью канала `t.me/s/<канал>` — там у каждого поста есть реакции и просмотры.
2. Берутся только посты с картинкой (видео и гифки пропускаются: `sendPhoto` их не отправит),
   не старше `TG_MAX_AGE_HOURS` и не опубликованные ранее (`state.json`).
3. Кандидаты сортируются по сумме реакций; публикуется лучший, у которого лайков не меньше
   `TG_MIN_LIKES`. Если он не отправился — следующий из `TG_TOP_N`.
4. Подпись — текст поста без ссылок, хэштегов и промо-строк канала-источника. Обычно у мемов
   подписи нет: картинка уходит без текста и без ссылки на оригинал (`TG_SOURCE_LINK = False`).

## Настройки (`news_monitor.py`)

`TG_HUMOR_FEEDS` — каналы-источники, `TG_MAX_AGE_HOURS` — окно свежести (72 ч),
`TG_MIN_LIKES` — порог лайков (40), `TG_TOP_N` — сколько кандидатов пробовать (3),
`TG_SOURCE_LINK` — ставить ли ссылку на оригинал (сейчас выключено), `SOURCE_LINK_*` — ссылки
в других рубриках.

Если `t.me` не открывается с текущей сети (бывает у российских провайдеров), можно задать
переменную окружения `TG_PROXY` с шаблоном прокси, например
`TG_PROXY="https://api.allorigins.win/raw?url={url}"`. С GitHub-раннеров `t.me` обычно доступен
и прокси не нужен.

## Запуск

```bash
python news_monitor.py           # опубликовать пост по текущему слоту
python news_monitor.py --check   # проверить, какие источники отвечают
RUBRIC=humor python news_monitor.py   # принудительно рубрика юмора
```

Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `GROQ_API_KEY_NEWS`.
